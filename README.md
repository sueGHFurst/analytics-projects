# analytics-projects

## Portfolio Architecture Aligned to These Four Modules

The portfolio structure is properly aligned across these four core analytics domains:

| Module Folder | Project Focus & Technical Framework |
| :--- | :--- |
| **`00-aws-cloud-sandbox/`** | Cloud infrastructure, Amazon S3 raw staging, automated Athena DDL, and serverless Python data pipelines (`boto3`, `PyAthena`). |
| **`01-customer-targeting-profitability/`** | Customer classification and profitability modeling comparing Logistic Regression, Random Forest, and Gradient Boosting to optimize targeting. |
| **`02-media-mix-modeling-optimization/`** | Marketing mix optimization and campaign channel performance analysis using multi-variable attribution and regression frameworks. |
| **`03-ab-testing-uplift-modeling/`** | Digital experimentation, SQL-driven hypothesis testing, sample ratio mismatch (SRM) checks, and causal uplift modeling via T-Learners (`LightGBM`). |
